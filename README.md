# Управление личными финансами

Консольное backend-приложение на Java 17 для учёта доходов и расходов, бюджетов по
категориям и статистики. Поддерживает несколько пользователей с авторизацией по логину
и паролю, сохраняет кошелёк каждого пользователя в файл и умеет переводить деньги между
кошельками.

## Возможности

- Регистрация и вход по логину и паролю (пароль хранится как PBKDF2-хеш с солью).
- Кошелёк привязан к пользователю: баланс, все операции, бюджеты по категориям.
- Доходы и расходы по категориям, бюджеты с остатком, переименование категорий.
- Сводка в формате задания: общий доход, доходы и расходы по категориям, бюджеты и остатки.
- Подсчёт по нескольким категориям и за период (`stats Еда,Такси --from 2026-11-01`).
  Если категория не найдена, приложение об этом сообщает.
- Оповещения: превышение бюджета, израсходовано 80% и 100% бюджета, расходы больше
  доходов, нулевой баланс.
- Данные хранятся в памяти во время работы. При выходе (`logout`/`exit`) кошелёк
  сохраняется в `data/wallets/<логин>.json`, при входе загружается обратно.
- Отчёт в файл, экспорт операций в CSV и JSON, импорт из JSON.
- Дополнительное задание: переводы между пользователями (`transfer bob 500`), у отправителя
  фиксируется расход, у получателя доход в категории «Перевод».
- Валидация ввода: суммы, даты, пустые значения, неизвестные команды и категории.

## Требования

- JDK 17+
- Maven 3.8+ (зависимость: Gson для JSON)

## Сборка и запуск

```bash
mvn clean package
java -jar target/personal-finance-1.0.0.jar          # данные в ./data
java -jar target/personal-finance-1.0.0.jar /my/dir  # свой каталог данных
```

## Команды

| Команда | Что делает |
|---|---|
| `register <логин> <пароль>` | регистрация |
| `login <логин> <пароль>` | вход, загрузка кошелька |
| `logout` | выход, сохранение кошелька |
| `income <сумма> <категория> [комментарий]` | добавить доход |
| `expense <сумма> <категория> [комментарий]` | добавить расход |
| `transfer <логин> <сумма> [комментарий]` | перевод другому пользователю |
| `budget <категория> <сумма>` | задать или изменить бюджет |
| `budget remove <категория>` | удалить бюджет |
| `budgets` | таблица бюджетов: лимит, потрачено, остаток |
| `rename <категория> <новое>` | переименовать категорию |
| `categories` | список категорий |
| `balance`, `summary`, `history [N]` | баланс, сводка, последние операции |
| `stats [кат1,кат2] [--from ГГГГ-ММ-ДД] [--to ГГГГ-ММ-ДД]` | статистика по выборке |
| `report <файл>` | сводка в текстовый файл |
| `export csv\|json <файл>` | выгрузка операций |
| `import <файл.json>` | загрузка операций и бюджетов |
| `help`, `exit` | справка, выход |

Названия из нескольких слов берутся в кавычки: `expense 3000 "Коммунальные услуги"`.
Сумму можно писать с точкой или запятой: `income 1500,50 Зарплата`.

## Архитектура

```
ru.mifi.finance
├── Main                     сборка зависимостей и запуск
├── domain/                  User, Wallet, Operation, OperationType, BudgetStatus
├── repository/              UserRepository, WalletRepository (интерфейсы)
│                            FileUserRepository, FileWalletRepository, WalletJson
├── service/                 AuthService     регистрация и вход
│                            FinanceService  операции, бюджеты, подсчёты, оповещения, переводы
│                            ReportService   сводки, CSV/JSON экспорт и импорт
│                            Session         текущий пользователь, загрузка/сохранение кошелька
│                            OperationFilter выборка по категориям и периоду
└── cli/                     ConsoleApp (цикл команд), CommandParser (аргументы с кавычками)
```

- Слои: модель → хранилища за интерфейсами → сервисы → CLI. CLI не работает с файлами
  напрямую, сервисы не печатают в консоль (оповещения возвращаются списком строк).
- Деньги хранятся в `BigDecimal`, без ошибок округления `double`.
- Время берётся из `java.time.Clock`, поэтому тесты детерминированы.
- Кошелёк пишется во временный файл и атомарно переименовывается, чтобы не повредить
  данные при сбое.

## Тестирование

```bash
mvn test
```

27 тестов (JUnit 5):

- `FinanceServiceTest` — расчёты на данных из примера задания, формат сводки, оповещения
  (превышение, 80%, перерасход, нулевой баланс), выборки по категориям и периоду,
  переименование, бюджеты, валидация сумм, переводы.
- `AuthServiceTest` — регистрация, вход, неверный пароль, повторная регистрация, хранение между запусками.
- `WalletStorageTest` — сохранение и загрузка кошелька, экспорт/импорт JSON, CSV.
- `ConsoleAppTest` — интеграционные сценарии через консоль: пример из задания,
  сохранение при выходе и загрузка при входе, перевод между пользователями,
  сообщения об ошибках, отчёт и экспорт в файлы.

## CI

GitHub Actions (`.github/workflows/ci.yml`) на каждый push и pull request проверяет
форматирование (Spotless, google-java-format), собирает проект, запускает тесты и
сохраняет jar как артефакт. Локально отформатировать код: `mvn spotless:apply`.
